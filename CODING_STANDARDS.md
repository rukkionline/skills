# Prose and style standards

The hard rules governing every piece of prose in this repo: `SKILL.md` files, docs pages, `README.md`, `CHANGELOG.md`, ADRs, changesets, and code comments. Docs-page-specific conventions (never name the author, branches as tables, dictionary terms) live in [writing-docs.md](./.agents/writing-docs.md).

## No em-dashes

Write without em-dashes anywhere in the repo's prose. This is a hard guardrail, not a preference. Where a sentence reaches for one, rewrite it with a comma, colon, period, parentheses, or a conjunction, whichever the sentence actually wants. Never do a blind character substitution (swapping the dash for a hyphen or a second dash); restructure the sentence instead.
